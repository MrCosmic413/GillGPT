# GillGPT

GillGPT is an AI-powered animatronic fish built by modifying a Big Mouth Billy Bass.

## Current Progress

- Raspberry Pi 4 configured
- Headless SSH access established
- Python development environment tested
- Original motor wiring reverse engineered
- TB6612FNG motor driver acquired

## Immediate Goal

Control Kevin's mouth and head/tail motors using Python and the Raspberry Pi.
