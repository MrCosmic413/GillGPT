# REV001 - Reverse Engineering Report

## Device

Big Mouth Billy Bass

---

## Objective

Determine how the original animatronic mechanism operates so that it can be replaced with a Raspberry Pi controller.

---

## Findings

### Motors

Motor A

Wire Colors:
- Orange
- Black

Function:
Head and Tail

Rotation:

Orange + / Black -
Head Movement

Orange - / Black +
Tail Movement

---

Motor B

Wire Colors

- Red
- Grey

Function

Mouth

Rotation

Red + / Grey -
Mouth Opens

Red - / Grey +
Mouth Closes

---

Power

Original Supply

6V

(4 AA Batteries)

---

Controller

Original controller board removed.

Future controller:

Raspberry Pi 4

TB6612FNG
